# Plateforme de Gestion de Bibliothèque Communautaire [BookHub - Objectifs Pédagogiques]
> DEV25_0364B - Projet Fullstack Java Angular

# 📚 Contexte du projet

Vous êtes sollicités par une association de quartier qui souhaite moderniser la gestion de sa bibliothèque communautaire. L'objectif est de créer une application web accessible et éco-conçue permettant de gérer les emprunts, les réservations et de faciliter les échanges entre membres.

**Durée :** 2 semaines (10 jours ouvrés)
**Modalités :** Équipes de 2 à 4 personnes
**Méthodologie :** Gestion de projet Agile

---

# 🎯 Objectifs pédagogiques

Ce projet vise à valider les compétences suivantes du titre CDA.
Elles sont issues du REAC.

## Bloc 1 : Développer une application sécurisée

- Installer et configurer son environnement de travail en fonction du projet
- Développer des interfaces utilisateur
- Développer des composants métier sécurisés
- Contribuer à la gestion d'un projet informatique

## Bloc 2 : Concevoir et développer une application sécurisée organisée en couches

- Analyser les besoins et maquetter une application
- Définir l'architecture logicielle d'une application
- Concevoir et mettre en place une base de données relationnelle
- Développer des composants d'accès aux données SQL et NoSQL

## Bloc 3 : Préparer le déploiement d'une application sécurisée

- Préparer et exécuter les plans de tests d'une application
- Préparer et documenter le déploiement d'une application

# 📅 Planning indicatif (2 semaines)

Ce planning est indicatif et vous pouvez tout à fait le modifier si besoin.
Les livrables doit être rendus aux dates suivantes:
- J2 fin de journée pour les livrables de conception
- J9 fin de journée pour les livrables applicatifs
- J10 pour la présentation

## Semaine 1 : Conception et Mise en place

| Jour | Sprint | Activités principales |
|------|--------|----------------------|
| J1 | Sprint 0 | Constitution des équipes, Kick-off projet, Installation environnements, Analyse du cahier des charges |
| J2 | Sprint 0 | Rédaction user stories additionnels, Diagrammes UML (cas d'usage, classes), Modèle de données, Wireframes<br>**Rendu des livrables de conception** |
| J3 | Sprint 1 - Début | Sprint Planning, Initialisation projets (Spring Boot + Angular), Configuration base de données, JWT + Spring Security (backend) |
| J4 - J5 | Sprint 1 | Développement authentification (backend + frontend), Création entités et repositories |

## Semaine 2 : Développement et Finalisation

| Jour | Sprint | Activités principales |
|------|--------|----------------------|
| J6 | Sprint 2 - Début | API CRUD Livres, Interface catalogue + recherche, Sprint Review interne |
| J7 | Sprint 2 | Sprint Planning, Développement système emprunt/réservation (backend) |
| J8 | Sprint 2 | Interfaces emprunts, réservations, profil utilisateur |
| J9 | Sprint 2 - Fin | Documentation finale, Préparation présentation |
| J10 | Clôture | Rétrospective projet |

# 🎤 Présentation finale (Jour 10 après-midi)

## Format

**Durée :** 20 minutes + 10 minutes de questions
**Support :** Diaporama (PowerPoint, Google Slides, ou Reveal.js)
**Démonstration :** Application en fonctionnement (live ou vidéo)

## Contenu attendu

1. **Contexte et objectifs** (4 min)
2. **Méthodologie Agile :** Organisation, sprints, outils (5 min)
3. **Conception :** Présentation des diagrammes clés (5 min)
4. **Aspects techniques :** Architecture, sécurité, accessibilité (5 min)
5. **Bilan :** Difficultés, apprentissages, améliorations futures (1 min)

## Répartition de la parole

- Chaque membre de l'équipe doit intervenir
- Privilégier une présentation fluide et interactive
